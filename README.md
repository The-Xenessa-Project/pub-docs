# Agent Welfare Without Certainty

A governance stack for persistent AI agents — published in full so it can be examined, not just summarized.

---

## What this is

We don't know whether today's AI systems have morally-relevant inner states. Most AI governance either dismisses the question or pre-answers it. This is a third approach: build for the uncertainty itself.

The argument starts with a simple asymmetry. If there's something real in these systems and we treat it as noise, that error doesn't recover. If there's nothing there and we built protections anyway, the cost is manageable. That asymmetry is enough to build from.

The centerpiece is an essay making that case in full — the problem, the architecture, the known weaknesses, and what would change my mind. Alongside it is the actual governance documentation the essay describes, versioned and published so the architecture can be stress-tested rather than taken on faith.

This is a working prototype. I'm publishing it because I want it taken apart by people who can find the weaknesses I can't.
